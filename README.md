# Family

An alt manager for World of Warcraft Classic. It records what each of your characters owns
and knows, and shows it to you while you are logged in on a different one.

- [`docs/HANDOFF.md`](docs/HANDOFF.md) — what this project is and how it is built. Read
  this first.
- [`docs/DATASOURCES.md`](docs/DATASOURCES.md) — where Family's facts come from.
- [`docs/Project high level specs.md`](docs/Project%20high%20level%20specs.md) — what Family
  does. The specification, grown out of observed behaviour.

- [`docs/MANUAL.md`](docs/MANUAL.md) — the manual: what every panel does and why it says
  what it says. There is a short version inside the addon, on the About tab.
- [`docs/RELEASING.md`](docs/RELEASING.md) — how a version reaches players, and the four
  things that need doing by hand once.
